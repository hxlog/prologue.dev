## Subscribe

The site publishes in three feed formats — paste whichever one your reader
prefers:

- [RSS2 Feed](/rss)
- [ATOM Feed](/atomfeed)
- [JSON Feed](/jsonfeed)

## How this site is built

Next.js App Router + React 19 + Tailwind CSS v4. All content is markdown under
`data/` — no database, no admin panel.

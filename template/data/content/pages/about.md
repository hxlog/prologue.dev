## 订阅

- [RSS2 Feed](/rss)
- [ATOM Feed](/atomfeed)
- [JSON Feed](/jsonfeed)

## 这个站点是怎么搭的

Next.js App Router + React 19 + Tailwind CSS v4，内容全部是 `data/` 下的 markdown 文件，没有数据库，也没有后台。
